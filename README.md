# Repositorio Visual Ecuatoriano (Proyecto de Titulación)
Un repositorio destinado a preservar la historia del diseño gráfico ecuatoriano
mediante la colaboración interuniversitaria.

Entre sus características únicas, está el uso de un motor de búsqueda semántico
para facilitar la recuperación de imágenes mediante consultas describiendo el contenido de la imagen
y no por términos exactos (como autor, año, género, etc.). De esta forma, se facilita el acceso 
al repositorio para todo tipo de usuarios.
